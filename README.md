Правила фронтенда:

## 1 -> Все страницы должны быть SSR

## 2 -> Корневой виджент должен быть SSR

## 3 -> Следуем картинке с учетом того что у нас app-routing и папка core доступна всему, кроме shared и его слайсам [alt text](image.png)

## 4 -> Между слоями импорты только через endpoints (index.ts)

## 5 -> Импорты типов должны быть обязательно с type

## 6 -> Внутри слоя core весь функционал работы с БД выносится в services по слайсам !!!

```JSON
{
  core: {
    services: {
      film: {},
      etcetra: {},
      etcetraTwo: {},
    }
  }
}
```

5. Ебана. пишем смачно bun run cap:open:android - открываем в андроид студио
