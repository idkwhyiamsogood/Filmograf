Правила:

1) сущности должны быть прописаны минималистично, если получается награможденно неправильное распределение в рамках инфраструкты
2) ui файлы в entities не должны иметь бизнес логики, процесса получения данных или их обработки, если имеют - это фичи или виджеты
3) в entities хранятся хуки и контекст для хранения и обновления данных, сами данные тут не обновляются - слой чисто для сущностей
